# Nelson's BetLab Tracker

A personal sports betting analytics dashboard for tracking daily cards, model performance, and bankroll history.

## Stack
- React + Vite
- Recharts
- localStorage for persistence

## Dev
```bash
npm install
npm run dev
```

## Deploy
Connected to Vercel. Push to main = auto deploy.

## Knowledge & chat context
- `KNOWLEDGE.md` — session rules/lessons, fetched automatically at the start of each chat.
- `obsidian-vault/` — the same knowledge as linked Obsidian notes (one per rule topic, one per
  session day) for easier browsing. See `obsidian-vault/README.md`.
